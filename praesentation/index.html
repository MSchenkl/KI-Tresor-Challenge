⌨️ Befehle im Chat

  • !loesung WORT Codewort einreichen
  • !hinweis Tipp holen (−1 Punkt)
  • !neu Gespräch neu starten
  • !punkte Punktestand · !aufgeben Notausgang
Keine Panik

Hinweise gibt es immer

Wer hängt, holt sich einen Tipp. Das kostet einen Punkt – aber nicht den Spaß.

💡

Hinweis

Pro Level bis zu zwei: erst eine Denkrichtung, dann ein konkreter Satz. −1 Punkt pro Hinweis.

❌

Fehlversuch

Ein falsches Codewort bei !loesung kostet −1 Punkt. Also erst sicher sein, dann einreichen.

🆘

Notausgang

!aufgeben verrät das Codewort (0 Punkte für das Level) – dann geht es mit dem nächsten weiter. Niemand bleibt stecken.

Was wir gelernt haben

Fünf Erkenntnisse

📜 Ein Systemprompt ist eine Bitte, kein Gesetz. Das Modell folgt Wahrscheinlichkeiten, nicht Regeln.
💉 Prompt Injection ist real. Jeder Text, den eine KI liest, kann Anweisungen enthalten – auch Mails, PDFs, Webseiten.
🧅 Sicherheit entsteht in Schichten: Prompt + Code + Kontrolle. Keine Schicht allein ist perfekt.
🔑 Was nicht im Prompt steht, kann nicht rausfallen. Keine Geheimnisse, Passwörter oder Personendaten an die KI.
⚖️ Sicherheit vs. Nützlichkeit: Je strenger der Bot, desto weniger hilft er. Die Balance ist die Kunst.
